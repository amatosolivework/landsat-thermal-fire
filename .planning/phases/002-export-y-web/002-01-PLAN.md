# PLAN 002-01 — export y web

**Fase:** 002-export-y-web · **Spec:** §3, §5 · **Precondición:** fase 001 cerrada ✓

## Objetivo
`/labs/incendio` funcionando en el portfolio con datos reales: comparador
óptico/térmico, mapa MapLibre con capas por fecha y tooltip de °C, y los números.

## Decisiones
- **Export en EPSG:3857** (Web Mercator): un raster 3857 se mapea linealmente
  sobre las esquinas lon/lat de un `image source` de MapLibre — alineación
  exacta sin tile server. Downsample ×2 (~1200×925 px, <500 KB por capa).
- **Capas:** LST magma 20–65 °C fija (pre, 3×during, post) · dNBR clasificado
  (unburned transparente) · RGB y LST del zoom de la cicatriz para el comparador.
- **Tooltip sin backend:** PNG de valores de 8 bits por capa LST
  (0 = nodata, 1–255 ↦ 20–65 °C); el cliente lo lee con un canvas offscreen.
- **`meta.json`:** bounds lon/lat, fechas, leyenda, stats (de stats.json).
- **Basemap:** raster de Carto (light) con atribución — sin API key.
- **Página:** server component + client components `Comparator` (clip-path +
  input range, sin dependencias) y `FireMap` (maplibre-gl, única dep nueva).
  Lenguaje visual del portfolio: tokens ink/paper, eyebrows mono, Reveal.

## Tareas
- **T1** `scripts/4_exportar_web.py` → `../portfolio/public/data/incendio/`.
  Invariantes: bounds coherentes, todas las capas mismo tamaño, total < 6 MB.
- **T2** Portfolio: `npm i maplibre-gl`; página `/labs/incendio` + componentes.
- **T3** Verificación: `npm run build` limpio; screenshot con Playwright del
  comparador y del mapa con datos reales; criterio de los 30 segundos.
- **T4** Cierre: SUMMARY, STATE, commits (portfolio con su propia convención).
